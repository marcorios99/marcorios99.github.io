Main projects

The two case studies that best represent my current profile.

01
FastAPI SQL Server Local LLM Structured JSON Safe SQL

Asistente empresarial de datos con IA local

Enterprise assistant for querying sales, products, inventory, and targets using natural language. The system converts user questions into a validated JSON intent, runs safe SQL queries, and returns answers as a summary, table, or chart.

  • The LLM does not generate or run SQL directly.
  • The backend validates the intent and builds controlled queries.
  • The response can be displayed as a summary, table, or visualization.

Synthetic use case based on real-world problems.

02
Python OpenCV OCR ICR OMR JSON/SQL

Procesamiento automático de formularios OCR/ICR/OMR

Automated capture system for processing scanned forms, detecting OMR marks, extracting fields through OCR/ICR, validating data, and exporting structured results for database loading or later review.

  • Image preprocessing and perspective correction.
  • Detection of areas, checkboxes, and OMR marks.
  • Validation, structured export, and low-confidence reporting.

Synthetic use case based on real-world problems.
