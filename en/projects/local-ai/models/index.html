Weights catalogue

The weights folder as a catalogue: what each file is, which repo it comes from, which license it falls under and where it fits in a 24 GB card. The tables group by role, and each GGUF's fit is computed against the VRAM the engine measured.

Origins were verified by exact byte size against each repo's tree in the Hugging Face API and by GGUF metadata. Of the 49 files, 48 land in a confirmed public repo; the q2_0 MTP draft was quantized here with XeStrata over the BF16 checkpoint's mtp.* tensors. The fit is an arithmetic budget against 23.91 GiB of useful VRAM, not a per-model measurement: the only model tried on this machine is Gyro-S.

Fit

How each weight enters 24 GB

The fit is computed with the rule below, not with load tests. The useful VRAM came from the engine's /health, which reports 25,669,140,480 bytes (23.91 GiB). GGUF weights are counted fully loaded into the GPU.

In VRAM
weights + f16 KV cache at 131k ≤ 23.91 GiB. The model fits with the full context and the default cache.
Reduced KV
fits only by dropping the cache to q8_0 or q4_0 with short context (≤32k); needs --cache-type-k and --cache-type-v at startup.
Split
the weights alone exceed VRAM and the engine splits them across VRAM, RAM and NVMe, as studied in the XeStrata entry.
With base
mmproj and drafts: they add to the model serving them; the mmproj adds about 0.6–0.9 GiB when an image comes in.
On demand
ComfyUI safetensors: loaded per run with --reserve-vram 5, never resident.

KV

The KV cache weighs more than the weights

The per-token cost comes from the layers, KV heads and head dimension read out of the GGUF. A dense 27B with 4 KV heads costs nearly three times what a MoE 35B with 2 does: that is why the dense ones only fit with a reduced cache.

Scope

What is verified and what is not

Verified

  • Exact byte size against each repo's recursive tree, and GGUF metadata read with XeStrata's reader.
  • Download revisions (the Hugging Face cache's .metadata) for the cases where the repo's main was requantized later.
  • Useful VRAM, KV arena and free VRAM from the live engine's /health.
  • Two shard pairs and the local MTP draft confirmed by hash and metadata name.

Out

  • Per-model performance: only Gyro-S runs and was measured on this machine; the other rows are budget, not a run.
  • Gated Hugging Face repos without a session: not checked, and none of the local weights depend on them.
  • The ComfyUI file catalogue is verified by size; image and video generation with its timings is the next planned entry.
  • The 2 Heretic weights are deliberately kept out of the catalogue.
