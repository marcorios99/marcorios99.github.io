Review note

Python

Python is used well when code is readable, predictable, and handles resources and errors clearly. For internal scripts and backend work, it is useful to review exceptions, context managers, iterators, generators, mutability, and basic structures.

Exceptions

Exceptions make it possible to handle errors without mixing the entire flow with conditionals. It is best to catch specific errors, add context, and keep unexpected failures visible. A silent except Exception can hide important failures in batch processes or APIs.

Context managers

A context manager controls entry into and exit from a block. The most common case is with open(...), which guarantees that files are closed even if an error occurs. It also appears with connections, locks, temporary resources, and redirected output.

Iterators and generators

An iterable can be traversed; an iterator keeps state; a generator produces values on demand with yield. They are useful for processing large files, streams, or sequences without loading everything into memory.

Mutability

Lists and dictionaries are mutable; strings and tuples are immutable. This matters when objects are passed to functions or structures are copied. Mutating a shared object can cause errors that are difficult to trace.

Typical questions

  • What is the difference between an iterable, iterator, and generator?
  • Why is with open(...) preferable to opening and closing manually?
  • What problems can mutating a shared object cause?
  • How would you log errors in a batch process?
