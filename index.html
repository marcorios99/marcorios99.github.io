Asistente empresarial de datos con IA local

Asistente empresarial para consultar ventas, productos, inventario y metas usando lenguaje natural. El sistema convierte preguntas del usuario en una intención JSON validada, ejecuta consultas SQL seguras y devuelve respuestas como resumen, tabla o gráfico.

02

Procesamiento automático de formularios OCR/ICR/OMR

FormVision · Open source

Pipeline template-driven para procesar formularios estructurados. Puede alinear scans contra una referencia, lee QR sobre la página completa y extrae fields OMR, OCR e ICR mediante ROIs definidas en el layout.

Demo pública con diez formularios sintéticos, ground truth y evaluación por lote en JSON.

PythonOpenCVQR/OMR/OCR/ICRLayouts y ROIsJSON/CSV/SQLite
