01

Asistente empresarial de datos con IA local

Asistente empresarial para consultar ventas, productos, inventario y metas usando lenguaje natural. El sistema convierte preguntas del usuario en una intención JSON validada, ejecuta consultas SQL seguras y devuelve respuestas como resumen, tabla o gráfico.

Pensado para consultar datos internos con IA local sin que el LLM genere ni ejecute SQL directamente.
