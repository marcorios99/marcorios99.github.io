Resumen

Soy ingeniero electronico orientado a backend y datos, con foco en sistemas de procesamiento documental. Me interesa construir soluciones que conviertan imagenes, formularios y PDFs en informacion consultable, validada y lista para operar desde APIs, web o Android.

  • Backend con Python, FastAPI, SQL Server y autenticacion JWT.
  • Captura documental con OCR/ICR/OMR, OpenCV, validaciones y salida estructurada.
  • Busqueda documental con LLM local, JSON de intencion y consultas seguras sobre datos procesados.
  • Clientes Android con Kotlin para busqueda, sesiones, visor de documentos e interaccion movil.

Stack y foco

Python FastAPI SQL Server OCR/ICR/OMR OpenCV Android/Kotlin LLM local JWT PDF processing

Lo que busco destacar

Sistemas pequenos pero completos: captura, backend, datos, busqueda y una experiencia que una persona pueda usar sin pelearse con el flujo.

Como trabajo

Prefiero APIs claras, validaciones explicitas, datos trazables y demos sinteticas que muestren el problema sin exponer informacion sensible.

Siguiente paso

Ordenar los case studies principales y luego preparar la version en ingles con el mismo mensaje, sin duplicar estructura innecesaria.
