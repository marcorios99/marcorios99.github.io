OCR, imagenes y documentos

El procesamiento documental combina imagen, extraccion y validacion. OCR lee texto, ICR intenta reconocer escritura o campos mas variables, y OMR detecta marcas. Antes de extraer datos, suele ser necesario mejorar la imagen y recortar regiones de interes.

OCR, ICR y OMR

OCR se enfoca en reconocer texto impreso o digitalizado. ICR apunta a escritura manual o campos con variacion alta. OMR detecta marcas, casillas o selecciones. En un formulario real pueden convivir las tres tecnicas: marcas para respuestas, texto impreso para etiquetas y campos escritos para identificacion.

Preprocesamiento

Antes de extraer informacion, la imagen suele necesitar escala de grises, binarizacion, reduccion de ruido, correccion de contraste o perspectiva. El objetivo es facilitar que el algoritmo vea la estructura relevante y no se distraiga con sombras, fondos, manchas o escaneos irregulares.

Contornos y ROIs

Los contornos ayudan a detectar regiones candidatas: casillas, tablas, bloques de texto o bordes de documento. Una ROI es una region de interes recortada para procesar un campo especifico. Definir buenas ROIs reduce falsos positivos y hace mas explicable el pipeline.

Validacion y evidencia

La extraccion no termina cuando el OCR devuelve texto. Hay que validar formato, rangos, campos requeridos, confianza y consistencia contra reglas de negocio. Guardar evidencia como imagen original, ROI procesada, checksum y resultado estructurado ayuda a auditar y corregir errores.
