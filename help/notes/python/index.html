Nota de repaso

Python

Python se usa bien cuando el codigo es legible, predecible y maneja recursos/errores con claridad. Para scripts internos y backend conviene repasar excepciones, context managers, iteradores, generadores, mutabilidad y estructuras basicas.

Excepciones

Las excepciones permiten manejar errores sin mezclar todo el flujo con condicionales. Lo sano es capturar errores especificos, agregar contexto y dejar visible lo inesperado. Un except Exception silencioso puede esconder fallas importantes en procesos batch o APIs.

Context managers

Un context manager controla entrada y salida de un bloque. El caso mas comun es with open(...), que garantiza cierre de archivos aunque ocurra un error. Tambien aparece en conexiones, locks, temporales y redireccion de salida.

Iteradores y generadores

Un iterable puede recorrerse; un iterador mantiene estado; un generador produce valores bajo demanda con yield. Son utiles para procesar archivos grandes, streams o secuencias sin cargar todo en memoria.

Mutabilidad

Listas y diccionarios son mutables; strings y tuplas son inmutables. Esta diferencia importa cuando pasas objetos a funciones o copias estructuras. Mutar un objeto compartido puede producir errores dificiles de seguir.
