Notas de repaso

Fundamentos para tener a mano antes de entrevistas, diseño de proyectos o revisiones tecnicas. Aqui no va tanto codigo, sino conceptos que conviene saber explicar.

Backend & APIs

  • REST, recursos, metodos HTTP e idempotencia.
  • Codigos HTTP clave: 200, 201, 400, 401, 403, 404, 409, 422, 500.
  • Autenticacion vs autorizacion; JWT, claims, expiracion y scopes.
  • Validacion de entrada, errores claros y contratos de respuesta.

Bases de datos

  • Indices: cuando ayudan, costo de escritura y riesgo de sobre-indexar.
  • Transacciones, commits, rollbacks y consistencia de cambios.
  • Joins, cardinalidad, duplicados y claves de negocio.
  • Auditoria: created_at, updated_at, usuario, estado y logs operativos.

IA aplicada a datos

  • El LLM debe interpretar intenciones, no ejecutar SQL directamente.
  • JSON estructurado: metricas, filtros, fechas, orden y formato de salida.
  • Validar contra un catalogo permitido antes de consultar la base de datos.
  • Separar respuesta explicativa, tabla y grafico para que la salida sea usable.
