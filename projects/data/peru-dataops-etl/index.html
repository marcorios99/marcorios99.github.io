ETL con observabilidad y trazabilidad

Ingesta de archivos operativos/contables (CSV) → validaciones de esquema y control de totales → deduplicación → carga a SQL → reporte automático y observabilidad. Reduce ~40% el tiempo de procesamiento.

Ver en GitHub ← Volver al inicio

Arquitectura del sistema

1

Ingesta automática

Monitoreo de carpetas para detectar nuevos archivos CSV operativos/contables.

2

Validación y control

Esquemas con Pandera/Great Expectations, control de totales y checksums.

3

Deduplicación idempotente

Proceso basado en claves de negocio y hash de contenido.

4

Carga transaccional

UPSERT incremental a SQL Server/PostgreSQL con rollback automático.

5

Observabilidad completa

Logs estructurados, métricas, alertas y orquestación con Prefect/Airflow.
