Data Logger IoT con FreeRTOS

Sistema multitarea para adquisición de sensores ambientales con envío robusto a API Python. Incluye manejo de colas, watchdog y journaling local.

  • Tareas FreeRTOS: lectura, almacenamiento, telemetría
  • Resiliencia: reconexión automática, backoff exponencial
  • Métricas: < 0.5% pérdida de datos en 24h

Driver I²C + OLED (Bare-Metal)

HAL mínima para display OLED SSD1306 con API limpia y medición de performance. Incluye pruebas con mocks y optimización de timing.

  • API: init(), draw_pixel(), draw_text(), flush()
  • Benchmark: tiempo de flush < 16ms @ 400kHz
  • Documentación: timing diagrams y pull-ups

Demo Modbus RTU (RS-485)

Maestro Modbus que lee registros de variador de frecuencia. Datos enviados a script Python para visualización y persistencia en SQL.

  • FSM: IDLE → TX → RX → PARSE → ERROR
  • Robustez: timeouts, reintentos, validación CRC
  • Integración: ETL Python + dashboard KPIs
