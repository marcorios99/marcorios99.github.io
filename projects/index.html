Proyectos de procesamiento documental

Estoy reorganizando el portfolio alrededor de proyectos que muestran mejor mi perfil actual: backend, datos, OCR/ICR/OMR, busqueda con IA y clientes Android. Los case studies usan datos sinteticos para explicar arquitectura, decisiones tecnicas y resultados sin exponer informacion sensible.

Case studies principales

Estos son los proyectos que guiaran la estructura nueva del sitio.

Python FastAPI SQL Server LLM local JWT

AI Document Search Platform

Plataforma para buscar documentos con lenguaje natural. El backend convierte la consulta en JSON validado, ejecuta una busqueda segura sobre metadata/contenido OCR y devuelve resultados listos para web o Android.

  • Arquitectura: cliente, API, autenticacion, SQL Server y motor de intencion.
  • Demo sintetica pensada para explicar el flujo sin datos privados.

Estado: case study publicado; demo sintetica en construccion.

Python OpenCV OCR ICR OMR

Smart Form Capture ICR/OMR

Flujo para extraer informacion desde formularios escaneados: limpieza de imagen, deteccion de marcas, lectura de texto/campos manuscritos, validaciones y persistencia estructurada.

  • Enfoque en datos confiables desde imagenes imperfectas.
  • Salida JSON/SQL para integrarse con APIs o tableros.

Estado: case study publicado; demo sintetica en construccion.

Python FastAPI SQL Server JWT PDFs

Document Processing API

API backend para recibir documentos, registrar metadata, controlar estados, validar resultados de extraccion, almacenar evidencia y exponer busquedas seguras.

  • Foco en endpoints claros, permisos, trazabilidad y estados del documento.
  • Puede consumir resultados de OCR/ICR/OMR sin que ese sea el centro del proyecto.

Estado: case study publicado; demo sintetica en construccion.

Kotlin Android Jetpack Compose Retrofit PDF viewer

Android Document Search Client

Cliente movil para consultar documentos procesados: login, JWT, PIN/biometria, busqueda en lenguaje natural, resultados agrupados y visor de imagenes/PDFs.

  • Experiencia pensada para usuarios que revisan documentos en campo u oficina.
  • Consume la misma API documental que la version web.

Estado: case study publicado; demo sintetica en construccion.
