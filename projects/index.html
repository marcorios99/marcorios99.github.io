Proyectos principales

Los dos case studies que mejor representan mi perfil actual.

01
FastAPI SQL Server LLM local JSON estructurado SQL seguro

Asistente empresarial de datos con IA local

Asistente empresarial para consultar ventas, productos, inventario y metas usando lenguaje natural. El sistema convierte preguntas del usuario en una intención JSON validada, ejecuta consultas SQL seguras y devuelve respuestas como resumen, tabla o gráfico.

  • El LLM no genera ni ejecuta SQL directamente.
  • El backend valida la intención y construye consultas controladas.
  • La respuesta puede mostrarse como resumen, tabla o visualización.

Caso de uso sintético basado en problemas reales.

02
Python OpenCV OMR/OCR/ICR docTR JSON/CSV/SQLite

Procesamiento automático de formularios OCR/ICR/OMR

Pipeline para formularios estructurados que puede alinear scans contra una referencia, leer QR y procesar fields OMR, OCR e ICR definidos mediante layouts y ROIs explícitas.

  • Alineamiento opcional contra una plantilla pública de referencia.
  • QR global y fields OMR/OCR/ICR definidos mediante ROIs.
  • Demo reproducible de diez formularios sintéticos con ground truth y evaluación por lote.

FormVision · Open source · Demo sintética reproducible
